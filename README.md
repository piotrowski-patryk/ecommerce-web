# 🛒 E-commerce Web

A frontend application for an e-commerce platform built with Nuxt.  
The application provides the user interface for browsing products, managing the shopping cart, and completing purchases.

## ⚙️ Setup

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
